# QuantumSwarm Formation (local bundle)

Este é o bundle local gerado com múltiplos módulos para desenvolvimento do projeto QuantumSwarm Formation.
Pontos principais:
- Padrão n_robots = 3
- Módulos implementados em core/
- Demos em demos/
- Testes em tests/
- CI em .github/workflows/ci.yml

Use:
- Criar venv, instalar requirements, executar pytest
- Executar demos/mission_critical_demo.py para um run rápido
